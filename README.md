# Antora Chattopadhyay, portfolio

This is the flat version: every file sits in one folder, with no sub-folders, so it uploads to GitHub in one go.

Upload everything in this folder to the root of your GitHub repo, then turn on Pages:
Settings > Pages > Deploy from a branch > main > / (root) > Save.

Keep all files together. The pages (.html) need style.css, main.js, the .jpg screens and the .woff2 fonts next to them.
Live site: https://antora-c.github.io/Portfolio/
